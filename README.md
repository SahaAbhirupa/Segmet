# SegMet

Paper: [SegMet: Inverse Full LH-Surface Design using Classification-Based Segmentation Algorithm](SegMet_Inverse_Full_LH-Surface_Design_Using_Classification-Based_Segmentation_Algorithm.pdf) (A. Saha, CLEO 2025)

## How to run

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

.venv/bin/python run_study.py --exp main   # generate synthetic data, train and evaluate all models
.venv/bin/python make_report.py            # fill in the table below
```

## Results

> **Note:** this is a recreation on **synthetic data** generated by a simplified physics-based
> simulator (`segmet/data.py`), so the paper's exact accuracies cannot be matched. The qualitative
> conclusion carries over: SegMet is far above every baseline. On this synthetic data, all three
> baselines sit at chance level (≈ 3.2%).

Setup: 100 samples split 60/20/20 (as in the paper), mean ± std over 3 seeds. Accuracy is the
fraction of unit cells whose Δx and Δy class (31 levels, −15…15 nm) is predicted exactly. Chance
is ≈ 3.2%.
